mue - 8086 assembler and emulator

The install tree mirrors emu8086 4.08 so that the editor, the examples
menu and the build outputs behave the way the original does:
  inc\        start-up templates (file > new)
  examples\   the examples menu and the file opened at start-up
  MyBuild\    <name>.com_ and its four sidecars
  MySource\   default Save As folder
  Options\    editor colours, fonts, hotkeys
  vdrive\     virtual drive letters A..F and tmp
  DEVICES\    external virtual devices
